## Stack

- **Runtime**: Node.js ≥ 18, pure CommonJS (`require`/`module.exports`)
- **LLM SDK**: `openai` (v4) — all models (Doubao, DeepSeek, Claude) via OpenAI-compatible API
- **Terminal UI**: `chalk` (colors), `boxen` (panels), `ora` (spinners), `inquirer` (prompts)
- **Markdown**: `marked` + `highlight.js` → terminal-colored output
- **File patching**: `diff` (line-level diffing for `patch_file` tool)

## Layout

| Dir/File | What's in it |
|----------|--------------|
| `bin/index.js` | CLI entry point — just `require('../src/main.js')` |
| `src/main.js` | REPL loop, agent orchestration, streaming display (boxen), raw-mode input |
| `src/config.js` | Env loading, model registry, interactive setup wizard |
| `src/session.js` | `ChatSession` class — message history with sliding-window compaction |
| `src/security.js` | Command blacklist, risk classification, user approval gate |
| `src/tools.js` | 8 tool impls + OpenAI function-calling schemas + dispatch table |
| `src/ui.js` | Markdown rendering, diff display, spinner wrapper |
| `src/wechat.js` | WeChat UIA monitor (persistent PowerShell child) + message send |
| `wechat_radar.ps1` | PowerShell script — polls WeChat UIA tree, outputs JSON lines |
| `.github/workflows/publish.yml` | CI: `npm ci` + `npm publish` on `v*` tag push |

## Commands

```bash
npm start          # Launch the REPL (node bin/index.js)
npm test           # Syntax-check all src/*.js + bin/index.js (node -c)
```

No build step — plain JS run directly. No linter or formatter configured.

## Conventions

- **CommonJS only**: `require()` and `module.exports`, no ES modules
- **File headers**: Every source file opens with `// ArkTerm — <Name>: <description>` banner
- **Section dividers**: `// ──` comment lines separate logical blocks within files
- **Commit messages**: AngularJS-style (auto-generated by `git_assistant` tool)
- **Module exports**: Each `src/*.js` file exports via a single `module.exports = …`

## Watch out for

- **`npm test` is syntax-only**: runs `node -c`, not a test suite. No runtime tests exist.
- **WeChat tools require Windows**: the PowerShell radar (`wechat_radar.ps1`) and UIA automation are Windows-only.
- **`.env` and `CLAUDE.md` are gitignored**: project-level env goes in `.env` (CWD), global in `~/.arkterm.env`.
